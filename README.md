# Sistema de Gestión de Eventos
Plataforma web escalable para la gestión integral de eventos en instituciones 
de educación superior, desarrollada con React + NestJS sobre AWS.

## Stack tecnológico
- **Frontend:** React + TypeScript + TailwindCSS
- **Backend:** NestJS + TypeORM + PostgreSQL
- **Cloud:** AWS (ECS Fargate, RDS, S3, IAM, CloudWatch)
- **DevOps:** Docker + GitHub Actions

## Estructura del proyecto
```
sistema-eventos/
├── frontend/        # React + TypeScript (Vite)
├── backend/         # NestJS + TypeORM
├── docs/            # Documentación técnica
└── docker-compose.yml
```
